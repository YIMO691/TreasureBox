## 如何使用

1. 在目录中选择符合当前工作需要的工具。
2. 打开使用入口，按照项目文档开始使用。Workflow-SOP 可直接阅读；Ares-Config-Copilot 需要下载 Windows x64 发布包并完成首次配置。
3. 工具的适用范围、当前状态、版本和使用许可，以各项目说明为准。

Workflow-SOP 当前为团队试行参考，Ares-Config-Copilot 当前为内部使用的 MVP。私有项目需要相应的 GitHub 访问权限；如无法打开，请通过公司内部渠道联系维护者。

## 收录与维护

新工具在对应分类中增加一条记录即可；有实际工具时再新增分类。各工具的代码、详细文档与版本继续在各自仓库维护。

- 添加或更新条目：参见 [贡献指南](CONTRIBUTING.md)。
- 链接失效、介绍错误或分类建议：在 [TreasureBox Issues](https://github.com/YIMO691/TreasureBox/issues/new/choose) 反馈。
- 工具安装、运行或功能问题：优先查看对应项目的支持说明。

维护者：[YIMO691](https://github.com/YIMO691)。
