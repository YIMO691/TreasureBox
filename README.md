## 研发协作

### Workflow-SOP

**把 AI 辅助研发的各个环节，串成可参考、可执行的协作流程。**

提供从理解问题、小步实现到验证交付的使用指引，配有按需选用的模板与教学示例。

> - 👥 **适用人员**：程序、需求方、测试、评审者
> - 📖 **使用方式**：直接阅读，按需将项目约定接入所用的 AI 工具
> - 🟡 **当前状态**：团队试行参考

- **开始一个任务**：参考快速开始，明确目标与本轮操作范围。
- **补齐协作记录**：按需要选择任务、功能、验证或交付模板。
- **学习具体做法**：通过教学示例了解各阶段如何配合。

[**开始阅读 →**](https://github.com/YIMO691/Workflow-SOP#从这里开始) · [完整流程](https://github.com/YIMO691/Workflow-SOP/blob/main/docs/WORKFLOW.md) · [项目仓库](https://github.com/YIMO691/Workflow-SOP)

## 策划工具

### Ares-Config-Copilot

**配表助手，让配置查询、改动审查和辅助修改有据可查。**

面向游戏 Excel 配置，通过本地工具完成查询、确定性校验和差异预览，并在确认后应用修改。

> - 👥 **适用人员**：游戏策划、配置维护者
> - 🖥️ **使用方式**：Windows x64 本地工具，首次使用需要绑定项目
> - 🟡 **当前状态**：MVP / 内部使用

- **查询当前配置**：定位工作簿、字段和记录，解释已登记关系。
- **检查本次改表**：查看前后差异、已登记关系的影响与校验结果。
- **辅助完成修改**：先查看修改预览，确认后备份、写入并复检。

[**下载工具 →**](https://github.com/YIMO691/Ares-Config-Copilot/releases) · [使用指南](https://github.com/YIMO691/Ares-Config-Copilot/blob/main/docs/USER_GUIDE.md) · [项目仓库](https://github.com/YIMO691/Ares-Config-Copilot)

### gfs-game-design-docs

**游戏策划文档，通过 AI 协作将想法和已有资料整理为可讨论的功能文档。**

围绕策划的日常表达整理需求草稿、修改摘要与关键问题，由策划确认玩法，各岗位依据共同的功能文档协作。

> - 👥 **适用人员**：游戏策划，以及接手需求的程序、美术、测试
> - 📖 **使用方式**：阅读项目指引，使用 Codex 配合仓库流程整理资料；私有仓库需要读取权限
> - 🚧 **当前状态**：实施中 / 未完成

- **整理需求资料**：从已有文档、草图或想法出发，形成可阅读的需求草稿。
- **保留关键问题**：记录尚未确认的玩法与规则，由策划决定后继续完善。
- **参考文档写法**：提供功能文档样例及按需使用的模板。

项目仍在完善中，实例包含待确认项；真实岗位接手、游戏交付及持续提效尚未验证。

[**查看项目 →**](https://github.com/YIMO691/gfs-game-design-docs) · [使用指引](https://github.com/YIMO691/gfs-game-design-docs/blob/main/START_HERE.md)

## 如何使用

**找到工具 → 打开使用入口 → 按项目指南开始。**

- 阅读类内容可直接查看；本地工具请下载发布包，并完成文档中的首次配置。
- 私有项目需要对应的 GitHub 访问权限；无法访问时，通过公司内部渠道联系维护者。
- 工具的最新状态、版本、支持范围及使用许可，以各项目说明为准。
